# Yogesh Mehta Functions

A repo of personal functions that I use in my research. The name is either `ymfuncs` or `myfuncs`, because I am Yogesh Mehta.

Many of these functions are wrappers of functions from cosmology libraries. However, installing all of these libraries, many of which have quite a few of their own dependencies, would result in essentially creating an entire python environment and make these highly inconvenient convenience functions. I therefore do not require any dependencies explicitly for this package. This also allows for greater flexibilty: you can `pip` install the whole package on any machine and only use the funcitons you currently want.
